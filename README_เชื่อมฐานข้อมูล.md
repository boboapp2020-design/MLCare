# MLCare — วิธีเชื่อมฐานข้อมูลจริง (Google Sheets)

ระบบทำงาน 2 โหมด สลับได้ด้วยการตั้งค่าไฟล์เดียว `config.js`

| โหมด | เงื่อนไข | เก็บข้อมูลที่ |
|---|---|---|
| **ออฟไลน์** (ค่าเริ่มต้น) | `API_URL = ""` | ในเบราว์เซอร์เครื่องนั้น (localStorage) |
| **ฐานข้อมูลจริง** | ใส่ `API_URL` แล้ว | Google Sheet (ใช้ร่วมกันทุกเครื่อง) |

---

## ขั้นตอนเปิดใช้ฐานข้อมูลจริง (ทำครั้งเดียว ~5 นาที)

### 1) ติดตั้งสคริปต์ลงชีต
1. เปิด Google Sheet ที่เก็บข้อมูล (แท็บ User / พนักงาน / ประเภทยา / อาการ)
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ **`Code.gs`** ลงไป → กด 💾 Save

### 2) Deploy เป็น Web App
1. กดปุ่ม **Deploy → New deployment**
2. ไอคอนเฟือง ⚙ → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. กด **Deploy** → อนุญาตสิทธิ์ (Authorize) ด้วยบัญชี Google ของคุณ
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 3) ผูก URL เข้าเว็บ
เปิดไฟล์ **`config.js`** แก้บรรทัดเดียว:
```js
const API_URL = "https://script.google.com/macros/s/XXXXXXXX/exec";
```
เปิดเว็บใหม่ (Ctrl+F5) — มุมล่างจะขึ้น **● เชื่อมฐานข้อมูล Google Sheets** สีเขียว

> เมื่อเชื่อมแล้ว: ข้อมูล user/พนักงาน/ยา/อาการ จะดึงสด ๆ จากชีต และทุกครั้งที่กด Submit
> ระบบจะเพิ่มแถวใหม่ในแท็บ **บันทึก** ของชีต (สร้างให้อัตโนมัติครั้งแรก) พร้อมโค้ด xxyyzz

## (แนะนำ) ใส่รหัสลับกันคนอื่นเรียก API
เพราะ URL แบบ "Anyone" ใครมีลิงก์ก็อ่านข้อมูลได้ ควรตั้ง token:
1. ใน **`Code.gs`** แก้ `var TOKEN = '';` → ใส่รหัสของคุณ เช่น `var TOKEN = 'mlcare-2024';` แล้ว **Deploy ใหม่** (Manage deployments → Edit → Version: New version)
2. ใน **`config.js`** ใส่ให้ตรงกัน: `const API_TOKEN = "mlcare-2024";`

## การแก้ข้อมูล
- **เพิ่ม/แก้พนักงาน, ยา, อาการ, user** → แก้ที่ Google Sheet ได้เลย เว็บดึงใหม่อัตโนมัติเมื่อรีเฟรช
- **การแมปยา↔อาการ** (สำหรับเตือนเมื่อยาไม่ตรงอาการ) อยู่ในไฟล์ `data.js` ช่อง `symptoms:` ของยาแต่ละตัว
  (ยาที่เพิ่มใหม่ในชีตแต่ยังไม่ได้แมป จะไม่ขึ้นเตือน)

## การเข้าสู่ระบบ
ใช้ได้หลายแบบ: **Badge + Pin** (เช่น `N001` / `1234`), หรือ **ชื่อ + Badge**

## หมายเหตุ
- ถ้าเปิดไฟล์แบบ `file://` แล้วเรียก API ไม่ได้ (บางเบราว์เซอร์บล็อก) ให้เอาไฟล์ไปวางบนโฮสต์ static เช่น GitHub Pages / เว็บภายในองค์กร แล้วเปิดผ่าน http(s)
